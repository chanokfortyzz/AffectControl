# Contributing

Keep the core framework-neutral, deterministic under tests, and free of product-specific private state. New appraisal providers must not embed credentials. New control policies must preserve hard user and safety constraints. Behavior-changing patches should include tests and, when applicable, benchmark evidence.

See [README.md](README.md) for the design and [docs/research-plan.md](docs/research-plan.md) for the evaluation plan.
