# Security

AffectControl is a control-bias library, not a permission system. Its outputs must never be treated as authorization for destructive, privileged, financial, credential, deployment, or account-changing actions.

Integrators should enforce hard safety and permission gates outside the affective control layer. Appraisal may influence soft ordering, attention, planning effort, memory salience, reflection, or preemption recommendations; it must not bypass explicit user constraints or external policy checks.

Do not embed API keys or private user data in appraisal providers, examples, tests, traces, or benchmark fixtures.
